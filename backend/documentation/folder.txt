2. services/

3. services/stages -> easier debugging and compiler phases are conceptually independent.

4. pipeline.py --> enforces in what order does this happens , domain logic 

5. sandbox => infrastructure safely execute untrusted compiler commands.

6. utils/ ->helpers 

7. schemas/ -> shape of data enters and leaves this system

8. core/config.py -> for centralization of the timeouts , memory limits , compiler flags , sandbox options
