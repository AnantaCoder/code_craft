## What I've Built

1. BACKEND (FastAPI + Python)
   - 7-stage compilation pipeline:
     * Lexical Analysis (tokenization)
     * Syntax Analysis (AST generation)  
     * Semantic Analysis (type checking)
     * Intermediate Code (LLVM IR)
     * Optimization (O2 passes)
     * Assembly Generation
     * Machine Code (disassembly)
   
   - Docker sandboxing with security:
     * Network disabled
     * Memory limits (128MB)
     * CPU limits (0.5 cores)
     * Non-root user execution
   
   - Cross-platform support:
     * Windows local with MinGW headers
     * Linux Docker container
     * Platform-aware clang flags

   - Collapsible nodes with animations
   - Flow particles on edges
   - Minimap for navigation
   - Zoom/pan controls
   - Responsive design

3. ARCHITECTURE HIGHLIGHTS
   - Clean separation: routes → services → stages
   - Platform config centralized in config.py
   - Response limiting for large includes (stdio.h)
