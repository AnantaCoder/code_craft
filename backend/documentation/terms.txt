The LLVM Core libraries provide a modern source- and target-independent optimizer, along with code generation support for many popular CPUs (as well as some less common ones!) These libraries are built around a well specified code representation known as the LLVM intermediate representation ("LLVM IR"). The LLVM Core libraries are well documented, and it is particularly easy to invent your own language (or port an existing compiler) to use LLVM as an optimizer and code generator.

Clang AST (Abstract Syntax Tree) is the structured, hierarchical representation of a C/C++ program produced by the Clang compiler frontend, where source code is parsed according to the language grammar and converted into a tree of nodes that represent declarations, expressions, statements, and types, while omitting irrelevant surface details such as formatting and comments.

In simpler words:
Clang AST is how Clang internally understands your C/C++ code—not as text, but as a precise tree of meaning that tools can analyze, transform, and reason about safely.

7. Parser (short definition):
A parser is the part of a compiler that takes tokens from the lexer and checks whether their order follows the language grammar, producing a structured representation of the program—usually an AST (Abstract Syntax Tree).
